# Fleet Economics API — Roadmap

## Мета проєкту

Fleet Economics API — REST API для управління автопарком і аналізу його економічної ефективності.

Проєкт розвивається у двох напрямках:
- **Backend engineering:** автентифікація, авторизація, CRUD, валідація, тестування, безпека та розгортання.
- **Fleet economics:** розрахунок доходів, витрат і ключових економічних показників транспортних засобів.

Лабораторна робота №21 визначає базові вимоги до REST API. Економічний модуль є подальшим розвитком проєкту та потенційною основою дипломної роботи.
